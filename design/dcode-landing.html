The problem

Search finds strings. Onboarding needs structure.

The questions that actually matter when you join a codebase are relational — who calls this?, what breaks if I change it? Text similarity can't see those.

◇what today's tools give you
Keyword search
Literal matches only. Miss authenticate() when you searched "login".
Flat vector RAG
Text similarity that loses the call graph — no idea what depends on what.
Generic chat assistants
Confident answers citing functions that don't exist.
◆what Dcode gives you
Hybrid retrieval
Exact symbols and semantic intent, fused in one pass.
A real call graph
Definitions, references, and dependencies — the structure behind the question.
Verified citations
Every reference checked against the index. Invented ones get stripped.
The pipeline

Index. Ask. Verify.

One asynchronous path from a raw Git URL to an answer you can trust.

→

Index the repo

Clone, slice at AST boundaries, embed every symbol, and rebuild the call graph — a dual index of vectors and structure, colocated in one store.

→

Ask in plain English

A ReAct agent routes your question through hybrid retrieval and atomic graph queries, reasoning across files instead of matching one.

Verify before you read

Every citation in the answer is checked against the symbol table. Groundedness is measured, not promised — the guardrail holds it at ≥ 95%.

Under the hood

Two indexes. One guardrail.

Structure-aware

Cosine similarity can tell you what code looks alike. A call graph tells you what actually calls what — so "trace this function's callers" becomes a real answer.

calls · imports · inherits · references

Grounded, not confident

The failure mode of code AI is a plausible symbol that doesn't exist. Dcode extracts every citation, checks it against the index, and strips what it can't verify.

groundedness ≥ 95%

Hybrid retrieval

Code needs exact matching (validate_token) and semantic intent ("auth-related code") at once. Sparse and dense run in parallel, fused by rank.

BM25 + dense + RRF + rerank
The evidence

We tried to prove ourselves wrong.

Most tools ship a demo. Dcode ships a falsifiable claim and a scoreboard.

The hypothesis: structure-aware retrieval beats flat RAG and keyword search on cross-file questions — by a margin set before measuring. Run against a five-rung baseline ladder on standard IR metrics. If it doesn't clear the bar, the result is recorded unsupported. The thresholds don't move after the numbers come in.
